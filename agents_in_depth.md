# Deep Dive: The Four Brains of Pacman AI

This document provides a comprehensive technical breakdown of the four distinct AI controllers built into the Pacman RL project. It details the underlying mathematics, how feature extraction powers learning, how the algorithms select actions, and specifically analyzes the real-world calculation logs (traces) generated by the Web UI.

---

## 1. Tabular Q-Learning (`QLearningAgent`)

### How it Works (The Theory)
Standard Q-Learning is a **"Model-Free, Off-Policy"** reinforcement learning algorithm. It attempts to explicitly memorize the quality (`Q-Value`) of *every single possible board layout* (State) paired with every possible move (Action). 

This is known as a tabular method because the AI is literally building a gigantic spreadsheet of `Dictionary[(Exact_Board_State, Direction)] = Score`.

### How it Learns (The Formula)
When Pacman takes a step and receives a reward (e.g., eating a pellet grants `+10`), it updates its memory using the Bellman Equation:

$$Q_{new}(s, a) = Q_{old}(s, a) + \alpha \left[ R + \gamma \max_{a'} Q(s', a') - Q_{old}(s, a) \right]$$

### The Real World Log Example
During execution, our Trace UI revealed this behavior natively:

```json
SELECT QLearningAgent → North (ε=0.30)
Q-Values: {"West":0,"Stop":0,"East":0,"North":0,"South":0}
```

**Why are they all Zero?**
This log brilliantly exposes the fatal flaw of Tabular Q-Learning in video games: **State-Space Explosion**. 
The exact position of Pacman, three moving ghosts, and 150 food dots means there are more board permutations than atoms in the universe. Because the agent almost *never* visits the exact same board permutation twice, it checks its "Memory Spreadsheet", realizes it has never seen this exact scenario, and returns a default `0.0` for all directions.

### Selection & Behaviors
Notice the `(ε=0.30)` in the log. `ε` stands for **Epsilon**. 
*   **70% of the time (Exploitation):** Pacman uses `argmax` to pick the highest number.
*   **30% of the time (Exploration):** Pacman completely ignores the math and throws the dice to walk in a random legal direction to discover new strategies. 

*(In the log above, he rolled the 30% chance and randomly decided to explore North).*

## 2. Approximate Q-Learning (`ApproxQLearningAgent`)

### How it Works (The Theory)
To fix the "State-Space Explosion" of Tabular Q-Learning, we bypass the gigantic spreadsheet and use **Function Approximation**. Instead of memorizing the board, the AI calculates Q-Values dynamically on-the-fly using a scoring system constructed of `Features` and `Weights`.

*   **Features:** Raw facts extracted from the board (e.g., "Is food near?", "Am I in danger?"). They are typically normalized between `0.0` and `1.0`.
*   **Weights:** The AI's *opinions* of those features. 

To determine a move's value, it simply multiplies them together:
$$Q(s, a) = (w_{danger} \cdot f_{danger}) + (w_{food} \cdot f_{food}) ... $$

### The Real World Log Example
Let's analyze a log captured during training:

```json
SELECT ApproxQLearningAgent → Stop (ε=0.30)
Q-Values: {
  "Stop": -51.62,
  "East": -49.81,
  "North": -38.71,
  "South": -75.22
}

Episode 5 Weights:
danger = -73.47
ateFood = +33.82
stopped = -12.59
```

**What is happening here?**
Rather than zeros, we see exact float calculations! 
1. The AI looks South. `FeatureExtractor` reports that moving South triggers `danger: 1.0` (a ghost is there!). 
2. The AI checks its weights. Its opinion of `danger` is a massive `-73.47`. 
3. It multiplies `1.0 * -73.47`, drastically lowering the South Q-Value to `-75.22`.
4. It realizes that South is suicide, and `North` (-38.71) is mathematically the "least terrible" option, steering Pacman away from the ghost!

### Selection & Behaviors
Because this agent relies simply on abstract rules (`danger = bad`), you can throw this AI into a completely brand new maze it has never seen before, and it will instantly know how to play perfectly without needing to memorize the new walls!

## 3. Approximate SARSA (`ApproxSarsaAgent`)

### How it Works (The Theory)
SARSA follows the exact same Feature/Weight approximation rules as `ApproxQLearningAgent`, but it changes one core philosophy: **It is On-Policy.**

*   **Q-Learning (Off-Policy):** Assumes that in the future, Pacman will always play perfectly (`max Q`). It is an optimist.
*   **SARSA (On-Policy):** Assumes that in the future, Pacman will continue making mistakes (factoring in his 30% `ε` Epsilon randomness). It is a realist.

### How it Learns (The Formula)
Notice that the Bellman equation no longer uses `max Q`:
$$Q_{new}(s, a) = Q_{old}(s, a) + \alpha \left[ R + \gamma \cdot Q(s', a_{actual}) - Q_{old}(s, a) \right]$$

### Selection & Behaviors
Because SARSA knows that it has a 30% chance of making a random move at any given time, it naturally learns to play much more cautiously than Q-Learning. If Q-Learning sees food directly next to a pit of lava, it will walk right along the edge because you "could" play perfectly. SARSA will refuse to go near the edge because it knows it might accidentally roll a random `ε` move and fall in!

## 4. Heuristic Reflex Agent (`TestAgent`)

### How it Works (The Theory)
The TestAgent operates on a completely different paradigm. It is **not** a Machine Learning agent. It does not use training episodes, it has no `α` Alpha (Learning Rate), it has no `γ` Gamma (Discount), and it has no Weights. It never learns.

Instead, it is a **Deterministic Reflex Agent**. It uses hardcoded mathematical formulas driven strictly by Manhattan Distance ($|x_1 - x_2| + |y_1 - y_2|$). 

### The Real World Log Example
When we connected `TestAgent` to the UI Trace Board, your log read:

```json
SELECT TestAgent (Heuristic) → East (ε=N/A)
Q-Values: {
  "West": -0.88,
  "East": +8.47,
  "North": -1.52
}
```

**Why does Epsilon say N/A?**
Because this AI is purely mathematical, it has no need to "explore". It handles every situation identically without random deviation, so Epsilon is disabled.

**Where do the numbers come from?**
It uses hard-programmed scoring algorithms inside `testAgents.py`. 
For every direction, it imagines taking the step. 
1. If that step puts Pacman exactly 1 block away from an active ghost, it injects an immediate rigid penalty: `Score -= 10000`.
2. For the closest food dot, it injects a reward fractional to the distance: `Score += 10.0 / (food_distance + 1)`.

In the log above, moving East yielded an `8.47` score because Pacman was stepping directly toward a dot. He picked East immediately because the math was indisputable. 

### Selection & Behaviors
While ML agents take thousands of episodes to slowly nudge their weights to realize "ghosts are bad", the `TestAgent` performs phenomenally on episode 1 because a human explicitly injected the logic `-10000 points if ghost is near`. It is aggressively efficient on small mazes, but it is "brittle" (it cannot creatively adapt to completely unforeseen mechanics the way a trained Neural Network or RL Model can).
